# 手話単語フラッシュ学習アプリ（ShuwaApp）

手話検定の試験対策や日常的な単語習得を目的に開発した、**単語と手話動画がランダムに連続再生されるWebアプリケーション**です。

## 💡 制作の背景・目的
前職で障害者福祉（就労支援）の職員として働いていた際、職場の聴覚障害のある方と「同じ言語でコミュニケーションがとれたらもっと楽しいはず」と思ったことをきっかけに、大阪市の手話奉仕員養成講座で手話を学び始めました（現在2年目・中上級コース受講中、全国手話検定試験4級・3級受験）。

学習を進める中で、次のような課題を感じていました。
* 既存の学習アプリは静止画（イラスト）やCGアバターが多く、実際の人間の手の動きやニュアンスが掴みにくい
* 動画教材は1単語ずつ手動でタップして再生するものが多く、**問題形式で次々とテンポよく復習できるツールがない**

「指文字だけでなく、実際の会話で使う手話単語をもっと気軽に楽しく覚えられたら、手話に挑戦する人が増えるはず」と考え、来年の手話検定2級合格に向けた自分自身の学習ツール兼、手話学習のハードルを下げるアプリとして開発しました。

---

## ✨ 主な機能・UI/UXのこだわり（第1弾リリース）
* **揺れる車内でもストレスなく使えるシンプル設計**：通勤・通学のバスや電車の中でも片手でサクッと学習できるよう、操作ボタンを「スタート」と「ストップ」の2つだけに絞りました。1問ごとにタップする手間をなくし、見るだけで連続学習できます。
* **フラッシュカード形式のタイムラグ演出**：まず「単語名」を画面中央に2秒間表示し、自分で手の動きを思い浮かべる間を作ってから、正解の「手話動画」を自動再生します。
* **ランダム連続出題＆指定区間再生**：データベースに登録された単語をランダムに選び、長時間の学習動画の中から該当単語の開始秒〜終了秒の区間だけを切り出してループ再生します。
* **ワンクリック停止**：ストップボタンでタイマー処理を安全に解除し、いつでも初期状態に戻せます。

## 🛠 使用技術・開発環境
* **バックエンド**：Java 21 / Servlet & JSP (Jakarta EE 10)
* **フロントエンド**：HTML / CSS / JavaScript / JSTL
* **データベース**：MariaDB (XAMPP / phpMyAdmin)
* **サーバー / IDE**：Apache Tomcat 10 / Eclipse

## 💻 開発で工夫した点・学び
* **「コードを読んで理解する」ことを重視した開発プロセス**：訓練校での学習の総復習として、まずは教科書を見ながら自力でコードを書くことに挑戦しました。授業で詳しく扱わなかったJavaScriptの非同期処理（`setTimeout`）やYouTube埋め込み制御については、AIのサポートも活用しつつ「丸写し」で終わらせず、1行ずつ処理の意味を解読・理解した上で実装しました。
* **DB接続情報の外部化（セキュリティ対策）**：GitHubでの公開にあたり、データベースのパスワード等の機密情報がコード上に残らないよう、`db.properties` ファイルへ切り出し、`.gitignore` で除外する構成にしました。

## 🚀 今後のアップデート展望
実際に手話を学ぶ方々の意見も取り入れながら、以下の機能を追加していく予定です。
* **検定の級別コース対応**：各級（4級・3級・2級など）の新出単語を網羅し、目標の級ごとに学習できる機能
* **最小限の操作で回せる「苦手単語」復習モード**：再生中に思い浮かばなかった単語だけ「復習ボタン」でマークし、後から苦手単語だけを連続再生。覚えたら「OKボタン」でリストから解除できる効率的な復習サイクル
* **学習時間の計測・記録機能**：スタートからストップまでの学習時間を計測（表示/非表示の切り替え可能）。会員登録したユーザーは日別の学習履歴を表で確認でき、未登録でもゲストとしてそのまま使える仕様
* **独自動画コンテンツへの移行**：将来的にはろう者の方にもご協力いただき、オリジナルの手話動画を撮影・収録してより見やすく実践的な教材へ発展させること
